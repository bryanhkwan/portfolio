# Bryan Kwan Portfolio

Static portfolio site for Bryan Kwan's analytics, BI, sports operations, and computer-vision work.

## Site Map

- `index.html` - homepage, proof summary, route hub, experience, skills, and contact.
- `projects.html` - dedicated project atlas with filters and live demo links.
- `computer-vision.html` - computer-vision lab page with heatmaps, annotated video, pipeline, and roadmap.
- `proof.html` - Toledo Athletics feature and MAC Tournament model-validation proof board.
- `portfolio-pages.css` - shared styling for the standalone pages.
- `portfolio-pages.js` - shared mobile-nav, reveal, card tilt, and project-filter behavior.

## Deployment Notes

- Commit the `compvision/` folder before deploying or the image/video assets will not appear.
- The annotated video uses `compvision/compvision-sample.mp4` and is intentionally loaded with `preload="none"` so the page stays responsive.
- `mac-tournament-model-validation.html.pdf`, `resume.pdf`, and `recommendation.pdf` are linked directly from the site.
